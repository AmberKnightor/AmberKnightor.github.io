The problem

Every release of a steel structure goes to the factory as a package: plate contours for the plasma/laser table, tube geometry for the tube laser, assembly drawings, bills of materials and shipping tags. Done by hand in Tekla, that is hours of exporting, renaming, sorting into folders and cross-checking quantities — and one missed part means a stopped production line.

  • Plates — DXF per position with a readable part mark, sorted by steel grade and thickness
  • Tubes — STEP/IGES in local coordinates, skewed cuts made machinable, part mark engraved
  • Drawings — assembly and bent-plate drawings with views, sections and dimensions
  • Reports — BOMs as real .xlsx, every file checked against the BOM before it ships

Case study: a steel structures design team

How the release of data to the factory went from a half-day job to a short routine.

Task

Every step was done by hand or spread across several programs. Plate drawings were created, marks were moved by hand and then printed. Tubes went through Tekla’s built-in MultiConverter, then through Grasshopper scripts to straighten skewed cuts and add engraving. Assembly drawings were built one by one.

Solution

Three connected tools started from inside Tekla: Report checker for plates and parts lists, Convertstp for tubes, Drawer for drawings. Skewed cuts are straightened and part marks engraved automatically, and the output is compared with the parts lists, so a person no longer has to catch a mismatch by eye.

The tools

Three desktop applications built for daily production use. Every screenshot below is the real program with its interface switched to English.

Report checker

Plate DXF export, Tekla reports to .xlsx and cross-checks · Python + C# helper

  • DXF straight from the model. A C# console helper drives the Tekla Open API, has Tekla write DSTV (NC1) for the selected plates and converts them to DXF R12: contour, cut-outs, round and slotted holes on separate layers.
  • Part marks that never hit a hole. The position mark is placed in the largest free area of the plate and shrunk if needed; a fixer moves marks that cross geometry in existing files.
  • Reports without Excel macros. Tekla report templates are run on the selection and re-saved as formatted .xlsx (Tekla itself only writes HTML “.xls”).
  • Checks that point back at the model. DXF and STEP folders are compared with the BOMs — missing, extra and wrong-quantity files are listed and the parts are selected in Tekla.
  • Factory-ready folders. Files renamed to position_thickness_qty, sorted by steel grade, thickness, tube type and profile; shipping tags generated as DXF.
  • Any Tekla version. Open API assemblies are loaded from the running Tekla (2016 → 2024 layouts), so one exe serves the whole team.
Watch the walkthrough on YouTube

Convertstp

Tekla tubes → STEP / IGES for tube laser cutting · C# WinForms

  • Real geometry, not a profile guess. Each tube goes through Tekla’s own IFC export, is moved into the part’s local coordinate system and converted to STEP or IGES (IfcConvert + own IGES writer with trimmed faces and true arcs).
  • Machinable cuts. Skewed wall cuts the laser cannot do are straightened; saddle cuts, slots for plates and round-tube intersections are handled separately.
  • Engraving in the geometry. The part mark is cut into the wide tube face — on the surface or through the wall — while the Tekla model stays untouched.
  • Batch preview. An HTML page shows every tube to scale with live sliders and per-tube overrides, and warns when the text would land on a cut-out.
  • Production details. Identical parts grouped, file names from a template, several Tekla instances detected and the right Open API channel picked automatically.
Watch the walkthrough on YouTube

Drawer

Automatic assembly and bent-plate drawings · C# · Tekla Drawing API

  • Assembly drawings in one pass. Main, top and bottom views, automatic sections at every detail, a 3D view, part marks on all views and the sheet size picked to fit.
  • Rebuild instead of redraw. Selected drawings get their views and dimensions regenerated after model changes; new drawings are created for selected parts.
  • Bent plates done right. The unfolded shape with dimensioned bend lines plus views of the bent part with overall size and bend radius.
  • Company standards kept. Uses the team’s view, section, dimension and layout property files; optional PDF output for every drawing.

Built into Tekla, deployed from one folder

The whole team runs the same versions without installers: a shared server folder, launcher macros and a custom tab in Applications & components.

Custom macro icons in the company tab of the Tekla catalog.

Launcher macros

A tiny C# macro copies the exe from the server to %LOCALAPPDATA% only when the server copy is newer, then starts it. The server file is never locked, so a new version is published at any time and picked up on the next click.

Company catalog tab

A custom *_ComponentCatalog.ac.xml in the firm folder adds a tab with the tools, shared components and plugins — with thumbnails — to every model of every user.

Shared components

An import macro brings .uel custom components from the firm folder into an open model, never overwrites components that already exist there, copies thumbnails and offers to save.

Shared plugins

Plugin DLLs are distributed to each workstation. Names are read from the [Plugin] attribute via reflection-only loading, and an installed plugin is never replaced — so existing parts are not regenerated and numbering stays intact.

Firm folder & templates

One XS_FIRM folder for attributes, report and drawing templates and mark templates, wired into every model’s advanced options — including the traps where Tekla rewrites options.ini.

Publishing

A publish script copies the exe through a temporary file and updates macros and icons only when their hash changes, so users never get a half-written file.

Launcher macro (C#, Tekla Akit) — the pattern behind every toolbar button 
// Starts the tool from the shared macro folder. The exe is copied to
// %LOCALAPPDATA% and run from there, so the server copy is never locked
// and can be replaced at any time.
public static void Run(Tekla.Technology.Akit.IScript akit)
{
    string localDir = Path.Combine(Environment.GetFolderPath(
        Environment.SpecialFolder.LocalApplicationData), AppName);
    string localExe = Path.Combine(localDir, AppName + ".exe");
    try
    {
        Directory.CreateDirectory(localDir);
        if (NeedsUpdate(ServerExe, localExe))
        {
            // temp file first: a network drop never breaks the working copy
            string temp = localExe + ".new";
            File.Copy(ServerExe, temp, true);
            File.SetLastWriteTimeUtc(temp, File.GetLastWriteTimeUtc(ServerExe));
            try { File.Delete(localExe); File.Move(temp, localExe); }
            catch (IOException) { } // old version still open — update next time
        }
    }
    catch (Exception) { } // server offline — run the last copied version
    Process.Start(new ProcessStartInfo(localExe) { WorkingDirectory = localDir, UseShellExecute = true });
}

Plugins & macros

Ten custom Tekla plugins (PluginBase with WPF dialogs) model the connections the team repeats hundreds of times, so they are placed in seconds and always come out the same.

  • Bracket plugins — a bent angle bracket between two frame tubes or at a picked point: flanges laid on the member faces, bend line and hole pattern calculated, bolts added.
  • Truss joint plugins — a family of joints for tube trusses in four variants.
  • Text and profile cut-outs — engraved text and profile-shaped cuts in plates.
  • Point placement and an inspector for checking joint parameters in the model.
  • UI automation macros — e.g. hiding distance variables in the custom component editor through Win32 when the API offers no way.

Why it matters

A plugin re-runs whenever the model changes. Shipping a new plugin version to a workstation in the middle of a project could silently rebuild parts and break part numbering — so the distribution macro only adds plugins that are missing and never touches installed ones.
